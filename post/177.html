밥솥 닭 한마리 만들기 + 닭 국수 만들기

밥솥 조리 팬에 옮긴 상태
닭 국수 콜라비 무생채 + 닭 국수 + 닭 구이 정식

소개

전과 동일한 레퍼토리로 역시 마트를 돌아 다니다가 닭볶음탕용 닭이 할인을 하길레 구매를 했다. 맨날 치킨 스톡과 닭가슴살로 닭 느낌만 냈지 한번도 닭 요리를 시도해본적이 없는데 최근 사용 하는 재료의 풀이 늘어 나면서 나름 자신감이 생긴거 같아 도전을 해보았다. 이번에 시도해볼 요리는 닭한마리인데... 사실 부산이 고향인 나는 살면서 닭한마리를 딱 한번밖에 안먹어 보았다. 그래서 닭한마리가 정확히 어떤 요리이고 어떻게 만드는지 모르지만 다양한 레시피와 경험을 살려 만들어 보았다. 거기다 간편한게 밥솥을 사용한...,

재료 (난이도 ✭✭)

  • 주재료:

    • 닭볶음탕용 손질 닭: 700g
      • 1kg을 구매 했지만 밥솥 사이즈 문제로 700g만 사용했다.
    • 대파 : 너무 크지 않은 사이즈 2대
    • 양파 : 반알
    • 당근 : 1/3개
      • 필수 아님
    • 다진 마늘 : 1sp
    • 다진 생강 : 1sp

  • 양념:

    • 미림 : 3sp
    • 치킨 스톡 : 0.5sp
      • 치킨 스톡이 없으면 소금을 사용 해도 된다.
    • 후추 : 0.5sp

  • 찍어 먹을 양념

    • 고추가루 : 2sp
    • 간장 : 1sp
    • 식초 : 2sp
    • 설탕 : 1sp
      • 매실청이나 생강청이 있다면 대신 사용하면 더 좋다.
    • 다진 마늘 : 1sp
    • 깨 : 0.3sp
    • 참기름 : 적당량
    • 쪽파 : 적당량
    • 연겨자 or 와사비 : 적당량
      • 집에 연겨자가 없어 와사비를 넣었는데 나쁘지 않은듯 하다.

조리 과정

  1. 깨끗히 씻은 대파와 양파, 당근을 적당한 크기로 썰고 밥솥에 깔아 준다.

    • 대파는 3 ~ 5cm 길이, 당근과 양파는 2 ~ 3cm 깍뚝썰어 준다.

  2. 닭을 손질하여 야채 위에 깔아 준다.

    • 닭 손질 하는 방법은 인터넷에 잘 정리 되어 있지만 사실 난 귀찮기도 하고 별 생각없이 그냥 사용 했다...

  3. 밥 솥에 미림 3sp, 치킨 스톡 0.5sp, 후추 0.5sp, 다진 마늘과 다진 생강을 1sp 씩 넣어 준다.

  4. 물을 400ml 정도 아래 야채가 잠길정도로 부어 준다.

    • 야채와 닭이 익으면서 수분이 나와 국물이 늘어나 물을 너무 많이 넣으면 넘칠수가 있다.

  5. 밥솥의 기능에 만능 찜 모드로 40분으로 맞추고 취사를 눌러 준다.

    • 만늠찜 모드가 없다면 일반 취사 모드로 해도 괜찮을것 같다.

  6. 닭 요리가 만들어 지면서 함께 찍어 먹을 소스를 만들어 준다.

    • 준비된 찍어 먹을 양념 재로를 모두 넣어주고 잘 섞었놓았다가 닭이 모두 완성되면 육수를 5sp 정도 넣어 섞어 완성한다.

  7. 취사가 끝나면 닭 고기 몇개를 갈라 보며 속까지 다 익었는지 확인하고 덜 익었다면 만능찜을 10분정도 더 진행한다.

  8. 맛있게 먹는다.

닭 국수

닭 한마리를 모두 먹고 나니 국물이 남았다. (물론 앞접시에 덜어 먹어 깨끗한 국물이다.) 보통은 한번에 칼국수까지 해먹던데 난 배가 불러 다음날 해먹기로 했다. 남은 닭 국물은 다시 한번 팔팔 끓이고 락앤락 그릇에 채를 받쳐 건더기를 걸러 보관했다. (앙파와 대파는 꾹꾹눌러 육수를 짜주었다.) 남은 살이 있다면? 살 부분만 잘 발라 보관해줬겠지만 난 살이 남지는 않았다

조리 과정

  1. 보관해두었던 닭육수를 냄비에 부어 다시 끓여준다.

  2. 양과 간을 보고 물과 소금, 간장, 치킨스톡등으로 양을 늘리고 간을 맞춰주고 계속 끓여준다.

  3. 면을 삶고 그릇에 옮겨준다. 혹시 남은 닭 고기가 있다면 고명으로 올려준다.

  4. 끓은 육수를 그릇에 부어주고 위에 고명 쪽파와 후추, 참기름을 둘러 준다.

  5. 맛있게 먹는다.
